# Ampliva

**Amplify your reach.**

Ampliva is a website-first promotional-services storefront built with a provider-agnostic architecture. The first provider integration targets the CID Growth Media API while keeping provider credentials and fulfillment logic server-side.

## Project goals

- Zero-cost development and initial hosting on Cloudflare
- Clean customer-facing service catalogue instead of exposing raw provider data
- Server-side provider integration and secret handling
- Margin-aware pricing and safe order flows
- Architecture that can support additional providers later

Initial project scaffold in progress.
